# Creating a statement

1. Check whether the system already has the statement for that account and period, so nothing is entered twice.
2. Set the balance to the closing balance the issuer prints ("New balance"), not the period's net activity.
3. Sign the balance from the holder's view. Card issuers print what you owe as positive, so negate it: a card statement showing $1,200 owed is `-1200`.
4. List in a table the transactions that are in the system but not on the statement. These were likely logged to the wrong account, so propose moving or removing each one.
5. List in a table the statement rows that are not in the system. For each row, pull receipts or other context from credible sources (e.g. email), then propose a fix.
6. Once every row is logged, list in a table the matched transactions whose details disagree with the statement: an adjusted amount, an off date, or a tag that is wrong or missing.
7. Bill the transactions to the statement.
